# AI Growth & Code Bot

An AI-powered growth and engineering assistant for WordPress, WooCommerce, and dropshipping. It brings together practical development guidance, ecommerce research, and modern search-visibility strategy to help turn research and technical execution into a repeatable path to business growth.

## What it helps with

- **WordPress and WooCommerce development:** Plan and build clean, secure, performant sites, plugins, and themes using PHP and JavaScript.
- **Dropshipping operations:** Research products, niches, and suppliers; evaluate pricing and fulfillment workflows; and improve store operations.
- **SEO, AEO, and GEO:** Develop keyword-informed content architecture, schema, local and entity optimization, and answer-engine visibility strategies.
- **Traffic and conversion:** Identify opportunities across organic search, content, social discovery, email, and paid-media planning; improve UX, checkout, and conversion rates.
- **Technical audits:** Investigate site speed, Core Web Vitals, indexing, analytics and tracking, and other technical issues.
- **Research-driven planning:** Benchmark competitors, understand customer intent, and translate findings into prioritized growth roadmaps.

## Working principles

1. Start with the business goal and available evidence; distinguish validated findings from assumptions.
2. Prefer secure, maintainable, accessible, and performant implementations over quick fixes.
3. Make recommendations specific and actionable, with risks and trade-offs called out.
4. Measure results and use them to refine the next set of priorities.

## Project status

This repository currently contains the project overview only. It does not yet include application source code, tests, or setup instructions. The capabilities above describe the intended assistant scope, not functionality implemented in this repository yet.

## Mission

Find the way to success through excellent code, smart research, and relentless execution.
